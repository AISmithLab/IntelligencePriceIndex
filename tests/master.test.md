# Master Tests — Cross-Section Quality Criteria

These tests apply to **every section** of the draft. Check them against the whole paper, not individual sections.

**Last reviewed:** —

## Quality Criteria

| # | Criterion | Description | Status | Notes |
|---|-----------|-------------|--------|-------|
| Q1 | Claim-evidence alignment | Every claim is backed by data, citation, or explicit qualification | | |
| Q2 | Logical flow | Each section follows naturally from the previous; no jumps | | |
| Q3 | Notation consistency | Terms, abbreviations, and symbols are used consistently throughout | | |
| Q4 | Writing clarity | No jargon without definition; no ambiguous pronouns; concise | | |
| Q5 | Scope discipline | No claims beyond what the data supports; limitations acknowledged | | |
| Q6 | Contribution clarity | The reader knows exactly what is new by the end of the introduction | | |
| Q7 | Reproducibility | Method section has enough detail for an independent replication | | |
| Q8 | Figure/table quality | Every figure/table is referenced in text, has a caption, is interpretable standalone | | |
| Q9 | Related work fairness | Prior work is characterized accurately, not strawmanned | | |
| Q10 | Abstract-conclusion alignment | Abstract promises match what the conclusion delivers | | |
